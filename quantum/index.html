What we know CONFIRMED

Quantinuum Helix — architecture, not a product

What we know CONFIRMED

  • Brother-test: error correction is the difference between a noisy demo and a computer that keeps its answer while it works. This week’s best result is a better blueprint — not a product.
  • Quantinuum C4-Helix on Helios (98 physical qubits). arXiv:2609.03194. Code [[20,2,6]] — ~3.5× lower spatial overhead vs rotated surface code (company framing).
  • Logical memory: 4.6×10⁻⁵ errors per logical qubit per QEC cycle. Logical two-qubit Clifford: 2.8×10⁻⁴ (~4.3× better than unencoded physical ~1.2×10⁻³). Inter-code GHZ fidelity lower bound 99.925%.
  • Missing for usefulness: sustained non-Clifford/magic-state without postselection; streaming real-time decoding.

Grade

  • HOLD early fault-tolerant architecture validation on commercial hardware.
  • REJECT “useful QC / crypto timeline moved.” Milestone ≠ commercial usefulness.
